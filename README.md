# UCB-GLOBES MS Data Visualization and Comparison Tool
Jupyter Notebook MS Data Visualization and Comparison Tool

A Jupyter Notebook for:
I. Downloading latest UCB-GLOBES MS database in csv format on googledrive
II. Filtering/Searching certain spectra based on metadata fields
III. Plotting two spectra for comparison:
		a) Relative abundance vs. m/z for spectrum 1
		b) Relative abundance vs. m/z for spectrum 2
		c) Mirror plot (Relative abundance of spectrum 1 has negative values, Relative abundance of spectrum 2 has negative values)
		d) Subtraction plot (Relative abundance spectrum 1 - Relative abundance spectrum 2)
		e) Scatter correlation plot of Relative abundance spectrum 1 vs Relative abundance spectrum 2 and calculated cosine angle similarity between spectra 1 and 2
IV. Calculation of cosine angle similarity values between multiple spectra selected and their differences in retention indices
